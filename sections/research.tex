\cvsection{Research Contributions \& Interests}

\cvpara{%
I \textbf{design and build robust data-intensive systems} that exploit the underlying \textbf{storage and processing hardware}, and \textbf{self-tune} to match workload and application requirements including optimizing for performance, tuning in presence of \textbf{workload uncertainty}, respecting \textbf{deletion} and \textbf{privacy-through-deletion} requirements, and capturing data \textbf{properties} including data and query \textbf{distribution} and \textbf{sortedness}. I also build \textbf{memory-efficient} algorithms and data systems designs that support low memory-to-data ratios. I focus on the internals of systems having contributed to \textbf{robust LSM-based designs} along with building \textbf{sortedness-aware tree indexing} and \textbf{update-aware bitmap indexing}. Finally, as moving data through the memory hierarchy remains a key bottleneck of data-intensive applications, I build new \textbf{hardware/software co-design} approaches that allow for \textbf{effortless data locality} via \textbf{in-memory data transformation} using custom hardware.}
